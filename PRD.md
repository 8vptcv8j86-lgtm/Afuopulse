# Afuopulse Product Requirements Document

Afuopulse is a multilingual, AI-native agricultural field intelligence platform.

## Priority capability roadmap
1. Farmer memory
2. Verified weather intelligence
3. Offline-first synchronization
4. Reviewed input recommendations
5. KandaSokoni buyer handoff
6. Cooperative aggregation
7. Privacy-preserving geospatial intelligence
8. Production analytics

Afuopulse provides field intelligence and evidence. Trade execution belongs in KandaSokoni or another approved provider under separate terms.
